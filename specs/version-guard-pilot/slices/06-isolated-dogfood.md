# Slice 06 — isolated active-process dogfood

## Owner

Controller/checker. Active installation is not delegated.

## Contract

Install the exact integrated wheel beside the retained prior environment, with hash-locked dependencies and a separate cache. Activate one isolated target harness/profile only. Preserve old environment/cache and a scoped rollback command.

## Acceptance

- installed module bytes match the reviewed wheel;
- native tool/adapter discovery identifies the new subprocess path;
- one real source-bearing context packet reaches actual pre-model assembly;
- a second fresh process reuses the exact cache correctly;
- unrelated profiles, system/durable messages, tools, and permissions remain unchanged;
- rollback command is inspected but not performed as a test.

## Stop rule

Any ambiguous process identity, shared-cache contamination, unrelated config diff, or missing source-bearing packet is NO-GO. Do not replace the daily default merely to make versions agree.
